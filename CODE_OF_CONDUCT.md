# Code of conduct

This repository is a technical learning resource. Contributors and participants are expected to:

- Keep discussion focused on the technical content — architecture, labs, security, CI/CD, and documentation quality.
- Give and receive feedback respectfully, including disagreement about technical approach.
- Avoid harassment, personal attacks, or discriminatory language in issues, discussions, and pull requests.

Reports of unacceptable behavior can be raised via GitHub's reporting tools on this repository. Maintainers may remove comments, close issues, or block participants who violate this policy.
